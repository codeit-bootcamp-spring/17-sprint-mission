# 17-sprint-mission
Spring 백엔드 트랙 17기 스프린트 미션 제출 리포지토리입니다.

---


## JCF와 File IO 비교
### JCF방식
- 데이터 영속성 없음
- 간단한 구현(직렬화 불필요)
- 처리 속도 빠름
### File IO 방식
- 데이터 영속성
- 구현 복잡함(직렬화, 예외처리)
- 처리 리소스 필요
- 파일 변조 가능성


## Repository 방식
- 디자인 패턴이다.
- 도메인 객체의 저장 및 조회 기능을 추사화하여, 비즈니스 로직이 구체적인 데이터 저장 기술에 의존하지 않도록 만드는 디자인 패턴
- 저장소에 있는 도메인 객체들을 마치 메모리에 존재하는 컬렉션처럼 다룰 수 있도록 하는 것.
